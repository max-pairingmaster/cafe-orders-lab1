## 📋 Опис проєкту

**CafeOrders** — система управління замовленнями в кафе, що дозволяє формувати рахунки зі страв і напоїв, призначати клієнтів та відстежувати життєвий цикл замовлення від створення до оплати.

### Доменна модель варіанта 12:

| Роль | Сутність у варіанті 12 | Опис |
| :--- | :--- | :--- |
| **Довідник учасників** | `Customer` | Клієнт кафе (ім'я, контакти, бали лояльності) |
| **Довідник об'єктів** | `MenuItem` (Product) | Страва / напій меню (назва, ціна, категорія, доступність) |
| **Документ** | `Order` | Замовлення із загальною сумою та прив'язкою до клієнта |
| **Позиція документа** | `OrderLine` | Конкретний елемент замовлення та його кількість |
| **Стани документа** | `OrderStatus` | `New`, `Preparing`, `Ready`, `Served`, `Paid`, `Cancelled` |

## 🛠️ Архітектура рішення

- **`CafeOrders.sln`** — кореневе рішення .NET 8.
- **`CafeOrders.Core`** — бібліотека класів (`classlib`), що містить бізнес-логіку та сутності доменної моделі.
- **`CafeOrders.App`** — консольний застосунок (`console`), що демонструє роботу із замовленнями кафе.
- **`.editorconfig`** — автоматизовані правила стилю коду (відступи, Allman-стиль дужок, `_camelCase` для приватних полів).
- **`Directory.Build.props`** — підключення аналізаторів Roslyn та StyleCop (`StyleCop.Analyzers`).
- **`CODING_STANDARD.md`** — офіційний регламент стандарту кодування команди.
