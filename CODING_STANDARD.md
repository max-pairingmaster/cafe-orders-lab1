# Стандарт кодування проєкту CafeOrders

Цей документ визначає стандарти написання та автоматичної перевірки коду для проєкту **CafeOrders** (Варіант № 12), обов'язкові для всіх учасників розробки.

---

## 📌 Зв'язок правил зі стандартами та лінтерами

| Пункт стандарту | Механізм контролю | Ідентифікатор / Налаштування | Опис |
| :--- | :--- | :--- | :--- |
| **Відступ 4 пробіли** | `.editorconfig` | `indent_size = 4` | Табуляція замінюється 4 пробілами |
| **Приватне поле з `_`** | Roslyn Naming Rules | `IDE1006` | Приватні поля починаються з `_` (`_camelCase`) |
| **Дужки обов'язкові** | `.editorconfig` | `csharp_prefer_braces = true` | Всі блоки `if/for/while` обрамляються `{}` |
| **Без зайвих пробілів** | StyleCop.Analyzers | `SA1028` | Заборонені trailing whitespace у кінці рядків |
| **Стиль Allman** | `.editorconfig` | `csharp_new_line_before_open_brace = all` | Фігурна дужка відкривається з нового рядка |
| **Ліміт довжини рядка** | `.editorconfig` | `max_line_length = 100` | Максимальна довжина фізичного рядка коду |

---

## ⚙️ Політика щодо StyleCop.Analyzers

Для запобігання надлишковим попередженням ("шуму") частину корпоративних правил Microsoft вимкнено з коментарями:

- **SA1633 (none)**: Вимкнено вимогу заголовка ліцензії в кожному навчальному файлі.
- **SA1101 (none)**: Вимкнено примусовий префікс `this.` перед членами класу.
- **SA1200 (none)**: Дозволено розміщення `using` на початку файлу (file-scoped directives).
- **SA1309 (none)**: Вимкнено правило, яке забороняє `_` для приватних полів (суперечило стандарту `_camelCase`).
- **SA0001 (none)**: Вимкнено обов'язковість XML-документації для всіх внутрішніх класів.
- **SA1028 (warning)**: Суворо увімкнено для підтримки чистоти форматування при спільній роботі через Git.

## 🚀 Команди перевірки форматування коду

```bash
# Перевірка наявності невідформатованого коду
dotnet format --verify-no-changes

# Автоматичне виправлення стилю
dotnet format

# Збірка з аналізаторами
dotnet build
```
