### Реєстр технічного боргу:
1. **TD-01 (Оманливе ім'я лічильника):** Змінна `kolvo` збільшувалася на 1 для кожного рядка чека, а не за сумарну кількість одиниць страв (`quantity`). Ім'я виправлено на `lineCount` відповідно до фактичної дії; коректний підрахунок штук передано на наступні роботи.
2. **TD-02 (CA1305 / Небезпечний парсинг):** Виклики `int.Parse` та `decimal.Parse` виконуються без `CultureInfo.InvariantCulture`, що залежить від поточної локалі ОС. Зафіксовано для переходу на типізовану модель `OrderLine`.
3. **TD-03 (Магічні рядкові масиви замість DTO):** Збереження даних замовлення як `List<string[]>` порушує типізацію та створює ризик помилок виходу за межі масиву `IndexOutOfRangeException`.

## 8. Завдання 6. Магічні числа та мертвий код

### Таблиця констант предметної області:
| Числовий літерал | Ім'я константи | Зміст та роль у предметній області |
| :--- | :--- | :--- |
| `0.2m` | `VatRate = 0.2m` | Ставка ПДВ (записано 0.2m без зайвих нулів для збереження шкали decimal) |
| `1000m` | `RegularDiscountThreshold` | Поріг суми замовлення для постійного покупця |
| `0.10m` | `RegularDiscountRate` | Розмір знижки для постійного покупця (10%) |
| `5000m` | `LargeOrderThreshold` | Поріг суми великого замовлення |
| `0.15m` | `LargeOrderDiscountRate` | Розмір оптової знижки на велике замовлення (15%) |
| `10` | `BulkLineCount` | Кількість позицій, починаючи з якої нараховується гуртова знижка |
| `100m` | `BulkDiscountAmount` | Фіксована знижка 100 грн за велику кількість позицій |
| `100` | `MaxLineCount` | Максимально дозволена кількість рядків у чеку |
| `3` | `MinCustomerNameLength` | Мінімальна валідна довжина імені клієнта |
| `0, 1, 2, 3` | `StatusNew ... StatusCancelled` | Числові коди статусів замовлення |

### Лістинг розрахунку суми після винесення констант:
```csharp
if (isRegularCustomer && total > RegularDiscountThreshold)
{
    total *= 1m - RegularDiscountRate;
}
else if (total > LargeOrderThreshold)
{
    total *= 1m - LargeOrderDiscountRate;
}

if (lineCount > BulkLineCount)
{
    total -= BulkDiscountAmount;
}

if (total < 0)
{
    total = 0;
}

total += total * VatRate;
return Math.Round(total, 2);
```

### Видалений мертвий код:
1. Закоментоване поле `prim` (`// public string prim;`).
2. Закоментований рядок старої знижки `// if (sum1 > 500) ...`.
3. Порожня самоприсвоювальна гілка `else { sum1 = sum1; }` (попередження CS1717).
4. Зайві невикористані імпорти `using System.Linq;`.
